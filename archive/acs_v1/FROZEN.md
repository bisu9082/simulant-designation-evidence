# ACS Sensors 평행본 — 폐기 (2026-11-08, Ku 승인)

이 폴더는 simulant 논문의 **ACS Sensors 판본**이었다. 2026-11-01 에
`73de480` 으로 새로 쓰기 시작했고 2026-11-08 에 폐기했다.

## 왜 폐기했는가

GATE 8 채점 이력이 라인별로 갈린다.

| 날짜 | 회차 | 합계 | 라인 |
|---|---|---|---|
| 10-14 | 4차 | **+3** | JHM |
| 10-14 | 5차 | **+6** | JHM |
| 11-02 ~ 11-07 | 7·8·9·10·12차 | 0 | ACS |
| 11-07 | 13차 | **−1** | ACS |

**+3 과 +6 은 전부 JHM 라인, 0 이하는 전부 ACS 라인이다.** ACS 라인은
한 번도 0 을 넘은 적이 없다.

그리고 이 라인은 JHM 라인에 없는 결함 넷을 들고 있었다.

1. 제목의 "Repeat Measurement" — 예치 표에 반복측정이 없다
   (`outputs/deltaE_noise.json` 의 `noise_floor` 가 `[수집 불가]`).
2. 역전 계수 13/34 를 헤드라인으로 — 추정량 수준을 맞추면 6 에서 30 까지
   움직이고, 그중 raw_max 는 포화 통계량이다.
3. 초록의 "sixteen authentic agents" — 측정은 16 이지만 서술자 축의 N 은
   11 이다 (3차 런 네 화합물은 코드 A-230/232/234/242 로 구조가
   "representative rather than assigned", HN 도 탈락).
4. Data Availability 가 원격에 없는 태그 `acs-submission-20261107` 을
   인쇄.

ACS Sensors 편집장 페르소나 판정도 Article 로는 세 번째 범위 반송이었다.
신규 측정 0, 신규 염료 0, 신규 소자 0 이고 세 원논문이 전부 자그룹
기발표다.
