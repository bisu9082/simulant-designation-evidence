# JHM 평행본 — 동결 (2026-11-04, 결정 J-C)

이 폴더는 simulant 논문의 **Journal of Hazardous Materials 판본**이다.
ACS Sensors 판본(`paper_acs/`)과는 제목과 프레이밍이 다른 별개의 원고다.

- 제목: *No Public Designation Names a Detection Measurement for the
  Simulants ...*
- 마지막 빌드: 2026-11-03 11:22 (본문 29쪽, SI 25쪽)
- 동결 시점 커밋: 작업 C 직후

## 왜 동결했는가

두 원고를 같은 산출물에 대조하면서 정합하게 유지하는 비용이 전파 실패로
세 번 돌아왔다. 마지막은 작업 C 에서였다. 중심화 '바닥' 논증을 철회할 때
이쪽 커버레터가 여유를 `0.013~0.064` 로 적고 있었는데, ACS본의
`0.0032~0.1576` 과도 다른 **네 셀만 계산했던 구판 수치**였다. 두 원고가
평행 사본이라는 사실 자체가 구판을 숨기는 자리를 만든다.

ACS Sensors 결과가 나오기 전에는 이쪽의 어떤 수치도 최종이 아니다. 지금
이식하면 두 번 집필하게 된다.

## 이 판본에 반영된 것

- 작업 C 의 철회분은 **반영했다.** 중심화 바닥 논증과 부호뒤집기 검정은
  저널 선택과 무관하게 수학이 틀린 것이므로 6곳을 교정하고 라벨순열 귀무
  표(`tab_premisenull.tex`)를 넣었다.

## 이 판본에 반영되지 않은 것

작업 A·B 의 나머지는 ACS본에만 있다.

- 형태 좌표 축소 민감도 (A-1)
- 제목에서 `Sixteen` 제거 (3-B)
- 초록의 휘발성 반사 채널 `q=0.0430` 편입 (2-A)
- 휘발성 4셀 일괄 Fisher → 채널별 BH (A-3)
- MDE 의 BH18 문턱과 배율 1.15 / 0.41 (A-4)
- DPGME/DMMP 회복률 귀속 교정 (89.8% 대 41.0%)
- 분석선택 넷 → 다섯, 유효매칭 범위 셋~여섯 → 영~여섯

## 되살리는 절차 (ACS 데스크리젝 시)

1. `verify_consistency.py` 의 `TEX` 를 `archive/jhm_v1/main.tex` 로 되돌리고
   `EXTRA_TEX` 에 이 폴더의 SI·커버레터를 다시 넣는다.
2. `UNQUOTED` 의 `ACS본 미수록 (J-C)` 블록 76건을 제거한다. 그 사실들은
   이 판본에만 적혀 있던 수치이고, 되돌리면 검사가 되살아난다.
3. `test_verify_consistency.py` 의 `ARCHIVED_JHM` 명단(56건)을 비우고
   `TEX`/`SUPP`/`SIDECAR` 를 이 폴더로 돌린다.
4. `FIGURES` 와 도판 신선도 목록을 이 판본 집합
   (`Fig_spaces`, `Fig_toxicity` 포함)으로 되돌린다.
5. 위 '반영되지 않은 것' 을 ACS본에서 이식한다. ACS본이 그 시점의 정본이다.
